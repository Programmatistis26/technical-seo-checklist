# Technical SEO Checklist

Basic technical SEO checklist for business websites.

## Core SEO Elements
- Optimized page titles
- Meta descriptions
- Proper heading structure
- Mobile responsiveness
- Fast loading speed
- SSL certificate
- XML sitemap
- Robots.txt configuration

## Performance
- Image optimization
- Caching
- Minified CSS/JS
- Core Web Vitals improvements

## Accessibility
- Alt text for images
- Proper contrast
- Keyboard navigation support

## Technical
- Clean URLs
- Structured data
- Canonical tags
- Error page handling
